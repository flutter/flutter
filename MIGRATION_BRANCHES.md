## Multi-Platform Compiler & Clang-Format Fixes in Introductory Commits

1. **Phase 1.1**: Added `using EmbedderTest::GetEmbedderContext;` to `EmbedderTestMultiBackend` and `EmbedderTestMatrix` (commit `a70f899767a`) to fix base class overload hiding under C++ derived class shadowing.
2. **Phase 1.1**: Removed unconditional `#include <unistd.h>` from `apk_asset_provider.cc` (commit `a70f899767a`) to resolve missing POSIX header compilation failure on Windows MSVC builds ahead of Phase 2.1 custom asset resolution.
3. **Phase 1.4**: Introduced `OSLibraryLoader` with `LoadDynamicLibrary` directly (commit `d0b8d31ac4b`) across interface, implementation, and call sites with strict clang-format multi-line wrapping to prevent Windows SDK `<libloaderapi.h>` macro collision (`#define LoadLibrary LoadLibraryW`).
4. **Phase 3.2**: Changed `EXPECT_EQ(ext_texture.destruction_callback, destruction_cb)` to `EXPECT_TRUE(ext_texture.destruction_callback == destruction_cb)` in `android_vulkan_texture_unittests.cc` (commit `2f77fdae3e7`) to prevent GoogleTest function pointer stream formatting error (`-Wmicrosoft-cast`) on MSVC.
